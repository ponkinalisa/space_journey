## 🎮 Игровой процесс

Ракета летит в космосе. Сверху падают метеориты. Ваша задача — уворачиваться от них и пролететь как можно дальше.

- 🚀 Ракета движется вверх автоматически
- ☄️ Метеориты падают сверху с разных точек
- 💥 При столкновении игра заканчивается
- 📊 Счёт растёт со сбором монет

---

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| ← / A   | Движение влево |
| → / D   | Движение вправо |

---

## 🚀 Как запустить

1. Скачай все файлы проекта
2. Открой `index.html` в браузере
3. Нажми на кнопку **Старт** (или пробел)
